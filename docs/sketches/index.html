Style rules used in SVG

  • Paper background #f8f6f1, pencil strokes #3a3a3a
  • Rounded line caps; Segoe Print / UI fonts for labels
  • No XML filters (broad viewer compatibility)
  • ASCII-friendly units (uF, not special punctuation)
